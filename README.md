# 領収書スキャン＆Excel出力

領収書をカメラで撮る／写真から選ぶだけで、端末内のOCR（Tesseract.js）が文字を読み取り、
日付・支払先・金額（税込）・税区分・インボイス番号・勘定科目を自動で埋めるWebアプリです。
確認して「表に追加」を押すと一覧に貯まり、1タップで `.xlsx`（シート「領収書明細」＋「科目別集計」、
合計はSUM数式）に出力できます。

- 画像はすべて端末内で処理され、外部サーバーへ送信されません（OCRもブラウザ内で実行）。
- 登録内容は端末の localStorage に保存されます。
- iPhone の Safari で開き、「ホーム画面に追加」するとアプリとして起動できます（PWA / standalone 表示）。

## 使い方（iPhone）

1. Safari でこのページを開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンから起動

## モード（4タブ）

- **領収書（青色申告）**：日々の経費を勘定科目ごとに整理する経費帳。
- **旅行費用**：円・ウォンが混在する旅行の支出を、設定レートで円換算して集計。
- **税務診断**：毎日21:30の自動監視との連動バナー、経費の赤・黄判定、源泉徴収票（複数枚）と所得控除の詳細入力、還付／納税のリアルタイム試算、**減価償却リスト（固定資産台帳）**。
- **PC版e-Tax 入力ナビ**：PCの確定申告書等作成コーナーの画面名どおりに進む5ステップ、決算書1〜3ページ目・確定申告書の転記ボード、マイナポータル連携ナビ、各種届出・申請ナビ。

## 減価償却リスト（固定資産台帳）

e-Tax 青色申告決算書3ページ目「減価償却費の計算」と同じ列（資産の名称等・取得年月日・取得価額・償却方法・耐用年数・償却率・本年中の償却期間・本年分の普通償却費・事業専用割合・本年分の必要経費算入額・期末未償却残高）で、資産の追加・編集ができます。

- 定額法／一括償却3年／少額特例（30万円未満）を切り替えると、その場で金額が再計算されます。
- 前年末未償却残高を入れると、期末残高と償却可能限度額（備忘価額1円）まで正しく追えます。
- 取得価額が未入力の資産、方法ごとの金額比較、経費帳の減価償却費との差額を注記します。
- Excel出力に「減価償却資産台帳」シートを追加します。

## PC連携（JSON書き出し / 読み込み）

スマホで「🖥️ PC用データ書き出し（.json）」を押して保存したファイルを、パソコンでこのページを開いて「📂 データ読み込み（.json）」で選ぶと、経費帳・固定資産台帳・源泉徴収票・所得控除・e-Taxの転記内容をそのままPCの大画面で使えます。データはGitHubに載らず、端末とファイルの中だけにあります。

## マイナポータル連携・各種届出

- マイナポータル（myna.go.jp）・国税庁の連携特設・作成コーナーへの公式リンクと、PC×スマホの連携手順。
- 控除証明書等の `.xml` を選ぶと、項目名と金額を読み取って参考表示し、所得控除欄へ反映できます（端末内で解析）。
- 住所変更（納税地の異動）・開業届・青色申告承認申請書・振替納税などの手順と公式ページへの導線。

## 税額計算の根拠（令和8年分）

- 給与所得控除：国税庁 No.1410（令和8年分・令和9年分＝最低保障額74万円、収入69万1,000円〜220万円未満の特例つき）
- 基礎控除：国税庁 No.1199（令和8年分＝合計所得489万円以下104万円／655万円以下67万円／2,350万円以下62万円）
- 生命保険料控除：新制度 各4万円・合計12万円、旧制度 各5万円、新旧合計12万円
- 地震保険料控除：地震保険料5万円＋旧長期損害保険料最大1万円、合計5万円
- 医療費控除：支払額−補填額−（10万円か総所得の5%の少ない方）、上限200万円
- 寄附金控除：寄附額（総所得の40%が限度）−2,000円
- 復興特別所得税：所得税の2.1%（令和19年分まで）
- 住民税：課税所得の10%−調整控除＋均等割（概算）

## ファイル構成

```
index.html   画面
app.js       OCR・解析・税額計算・Excel出力のロジック
manifest.json / icon-*.png   PWA（ホーム画面アプリ）用
vendor/      Tesseract.js（OCRエンジン・日本語/韓国語/英語の辞書）、SheetJS（Excel出力）
```

## ローカルで動かす

静的ファイルのみなので、任意の静的サーバーで配信できます。

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

OCRエンジンの辞書（`vendor/tessdata/`）を読み込むため、`file://` ではなくHTTPで開いてください。
